# 向量检索接入阿里百炼 API — 成本估算

> 决策（2026-07-21 Boss 拍板）：LLM 判决继续走 DeepSeek API；向量检索（embedding + rerank）切阿里系 API。
> 本文件估算「跑一次向量」的相关成本（人民币，阿里云百炼国内区单价）。

## 1. 选定模型（阿里系）

| 环节 | 模型 | 单价 | 备注 |
|---|---|---|---|
| Embedding（向量化） | `text-embedding-v3` | 0.6 元/百万 token（仅输入计费） | 百炼通用强模型；若需**严格对齐本地 Qwen3-Embedding-4B 语义**，改用硅基流动 `qwen3-embedding-4b`（OpenAI 兼容，价格相近） |
| Rerank（精排） | `qwen3-rerank` | 0.6 元/百万 token（仅输入计费） | 百炼原生，与本地 Qwen3-Reranker-4B 同源 |
| BM25（稀疏检索） | 本地 | 免费 | 不参与 API 成本 |
| RRF 融合 | 本地 | 免费 | 不参与 API 成本 |

## 2. 语料规模（实测）

| 语料 | chunks | 总字符 | 估算 token |
|---|---|---|---|
| 农场证据（99 case） | 8,400 | 11,190,342 | ≈ 11.2M |
| 法规条款（共享 1 份 PDF） | 413 | ≈ 268,000 | ≈ 0.27M |
| **合计（一次性向量化）** | 8,813 | ≈ 11.46M | **≈ 11.5M** |

> 中文 token ≈ 字符数（Qwen tokenizer 中文字级），系数取 1.0，保守。
> 单 chunk 平均 1332 字符；运行时 rerank 的 doc 按此均值计。

## 3. 成本明细

### 3.1 一次性：语料向量化建索引（只跑一次）
- 证据 11.2M + 法规 0.27M ≈ **11.5M token**
- 费用 = 11.5 × 0.6 = **≈ 6.9 元**
- 建好索引后，除非语料变更，否则不复跑。

### 3.2 每跑一次完整推理（4100 决策 = 100 case × 41 CP）

**(a) query embedding（CP 描述作为检索 query）**
- 不缓存：4100 × ~300 token ≈ 1.23M token → **0.74 元**
- 缓存 41 个独特 CP query：≈ 12k token → **≈ 0 元**（可忽略）

**(b) rerank（每 (case,CP) 对 top_k=8 候选精排）**
- 单次：query 300 + 8 doc × 1332 = 300 + 10,656 ≈ 10,956 token
- 4100 次 × 10,956 = **44.9M token**
- 费用 = 44.9 × 0.6 = **≈ 26.9 元**

**(c) 稠密检索 corpus 向量**：已在 3.1 一次性付清，运行时只向量化 query（含在 a）。

**每跑一次完整推理合计 ≈ 0.7 + 26.9 ≈ 27.6 元**（rerank 占 97%）

## 4. 与本地 GPU（AutoDL RTX4090 24G）对比

| 维度 | 阿里 API | 本地 Qwen3-4B |
|---|---|---|
| 一次性建索引 | ≈ 6.9 元 | GPU 已租，边际≈0 |
| 每跑一次推理 | ≈ 27.6 元 | 边际 ≈ 1–2 元（GPU 已开机则≈0） |
| 权重下载 | 无 | 16G，踩过 xet 403 坑 |
| 运维 | 无（API 托管） | torch cu 匹配 / 开机 SSH / 停机 |
| 数据出域 | 是（但 LLM 判决已走 DeepSeek，证据本已出域） | 否 |
| 可复现 | 厂商锁版本（可锁定 model 名） | 完全可控 |

**结论**：若只跑 1–3 次完整推理，API（~28–83 元）比 GPU 租几天更省且免运维；
若频繁调参（跑 20 次 ≈ 550 元），本地 GPU 反而更省。建议 API 为主、本地留兜底。

## 5. 降本建议
- **rerank top_k 8 → 5**：44.9M → 28.5M token，单次降到 ≈ 17 元（省 38%）
- **Batch API（异步 5 折）**：rerank 可降至 ≈ 13.5 元/次（需百炼/硅基流动支持批量）
- **query 缓存**：CP 描述 41 个独特 query 缓存，省 0.7 元（小）
- 调参阶段只对抽样 case（如 10 case = 410 决策）跑，单次成本 ≈ 2.7 元

## 6. 备注 / 风险
- 红线文件（checkingpoints 红线表）严禁进任何 AI，与调 API 无关，不受影响。
- 阿里百炼 embedding 默认 `text-embedding-v3`（非 qwen3-embedding）；如要语义完全对齐本地权重，embedding 改走硅基流动 `qwen3-embedding-4b`。
- 成本基于 2026-07-21 百炼公开定价（国内区 0.6 元/百万 token），以实际账单为准。
